# Деплой SoundGoodizer на Railway

Railway — стабильный хостинг без засыпания, PostgreSQL встроен, бесплатный план работает постоянно.

---

## Шаг 1 — Загрузить проект на GitHub

Если репозиторий ещё не создан:

1. Зайди на https://github.com и создай новый репозиторий (например `soundgoodizer`)
2. В папке проекта выполни в терминале:

```bash
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/ТВО_ИМЯ/soundgoodizer.git
git push -u origin main
```

Если репозиторий уже есть — просто запушь изменения:
```bash
git add .
git commit -m "Prepare for Railway deploy"
git push
```

---

## Шаг 2 — Зарегистрироваться на Railway

1. Зайди на https://railway.app
2. Нажми **Login** → **Login with GitHub**
3. Авторизуй Railway в GitHub

> Для стабильной работы рекомендуется привязать карту (Hobby план $5/мес).
> Без карты — 500 часов/месяц бесплатно, чего хватит на ~20 дней.
> **Для защиты лучше привязать карту заранее.**

---

## Шаг 3 — Создать проект на Railway

1. Нажми **New Project**
2. Выбери **Deploy from GitHub repo**
3. Найди и выбери репозиторий `soundgoodizer`
4. Railway автоматически определит Python и начнёт сборку

---

## Шаг 4 — Добавить PostgreSQL

1. В открытом проекте нажми **+ Create** → **Database** → **Add PostgreSQL**
2. Railway создаст базу и автоматически добавит переменную `DATABASE_URL` в твой сервис
3. Подожди ~1 минуту пока база поднимется

---

## Шаг 5 — Настроить переменные окружения

В разделе твоего сервиса (не базы) → вкладка **Variables** → добавь:

| Переменная | Значение |
|---|---|
| `SECRET_KEY` | любой длинный случайный набор символов |
| `MAIL_USERNAME` | e.saltymakov06@gmail.com |
| `MAIL_PASSWORD` | vbfm gowd elnj nxjg |
| `MAIL_SERVER` | smtp.gmail.com |
| `MAIL_PORT` | 587 |

`DATABASE_URL` Railway добавит сам — не трогай.

---

## Шаг 6 — Залить данные в базу

После того как PostgreSQL поднялся:

1. В Railway открой сервис **PostgreSQL** → вкладка **Connect**
2. Скопируй строку подключения (Public URL)
3. Подключись через pgAdmin или psql и выполни SQL-скрипты из папки `sql запросы/` в порядке:
   - `создание таблиц с описанием.sql`
   - `вставка данных(базовых).sql`
   - `еще бренды_1.sql`, `еще_бренды_2.sql`
   - `еще инструменты_1.sql`, `еще_инструменты_2.sql`
   - `индексы.sql`

---

## Шаг 7 — Проверить деплой

1. В Railway → твой сервис → вкладка **Deployments** — смотри логи сборки
2. После успешного деплоя → вкладка **Settings** → раздел **Domains** → нажми **Generate Domain**
3. Получишь адрес вида: `https://soundgoodizer-production.up.railway.app`

---

## Важно про загруженные файлы

Railway имеет **эфемерную файловую систему** — файлы загруженные пользователями (аватарки, фото ремонтов) удаляются при каждом редеплое. Для защиты это не критично если не планируешь делать редеплои в день защиты.

**Не делай git push в день защиты** — это вызовет редеплой и временную недоступность (~1-2 минуты).

## Если что-то пошло не так

- Логи деплоя: Railway → сервис → **Deployments** → кликни на деплой → **View Logs**
- Логи в реальном времени: вкладка **Observability** → **Logs**
- Перезапустить сервис: **Deployments** → три точки → **Redeploy**
